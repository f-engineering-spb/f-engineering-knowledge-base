# Визуальный стиль F-Engineering

> **Статус**: Mandatory / Single Source of Truth (Обязательный стандарт / Единственный источник истины)

---

## 1. Общие правила

1. **Область применения**: Все HTML, Markdown, Google Таблицы (Google Sheets), Google Документы (Google Docs), Презентации (Slides), просмотрщики Apps Script (Apps Script viewer), отчёты, реестры, карточки, вьюеры и интерфейсы в рамках пространства GitHub и репозиториев `f-engineering-spb` должны строго использовать только цветовые палитры из этого документа.
2. **Запрет**: Категорически запрещается использовать устаревшие палитры, случайные цвета, экспериментальные цветовые схемы или стили из прежних артефактов, если они явно не описаны в данном руководстве.
3. **Правило изменений**: Добавление новой палитры или изменение существующей допускается исключительно через отдельный Pull Request (PR), согласованный со всей командой.

---

## 2. Базовые параметры текста и интерфейса

При создании текстовых документов и веб-интерфейсов необходимо использовать следующие базовые параметры:

* **Основной текст (Main Text)**: `#1f2328`
* **Вторичный текст (Secondary Text)**: `#59636e`
* **Базовая граница (Base Border)**: `#d9dedc`
* **Основной шрифт (Font Family)**: `Segoe UI, -apple-system, BlinkMacSystemFont, Helvetica Neue, Arial, sans-serif`
* **Моноширинный шрифт (Monospace Font Family)**: `Segoe UI Mono, Consolas, Courier New, monospace`

## 4. Инверсные палитры (Inverted Palettes)

**Правило инверсии**: `Layer 1` и `Layer 3` меняются местами, `Layer 2` остаётся без изменений.
Инверсная схема применяется, когда основной фоновый блок должен быть более насыщенным, а вложенные карточки/кнопки — более светлыми. Также вводится дополнительный контрастный цвет границы (`Border Strong`).

## 5. Рекомендации по выбору палитры

При создании новых документов или интерфейсов руководствуйтесь следующей таблицей выбора:

* **GitHub / Правила / Реестры / Таблицы** &rarr; `P01 Direct` (GitHub Light)
* **Универсальный рабочий HTML / Просмотрщик** &rarr; `P02 Direct` (Apple Gray)
* **Методичка / Длинное чтение** &rarr; `P03 Direct` (Warm Paper)
* **Регламент / Бизнес-процесс** &rarr; `P04 Direct` (Sage)
* **Техническая аварийная инструкция** &rarr; `P05 Direct` (Sand)
* **Сравнение / Варианты решений** &rarr; `P06 Direct` (Mist Lavender)
* **AI-инструмент / Технологическая матрица** &rarr; `P07 Direct` (Ice Blue)
* **Использование Inverted схем**: Применяется *только* в тех случаях, когда требуется более глубокий/насыщенный общий фон, на котором располагаются контрастные светлые карточки, кнопки или поля ввода.
