# Бизнес-процессы

Этот раздел хранит повторяемые модули бизнес-процессов F-Engineering.

Модуль - это самостоятельный кирпичик работы, который можно вставлять в разные
процессы компании без привязки к одному объекту. Модуль описывает проблему,
пользователей, входные данные, порядок работы, результат и контроль готовности.

Использовать этот раздел нужно тогда, когда проектный опыт превращается в
повторяемый способ ускорить работу: поиск информации, анализ, подготовку КП,
старт проектирования, управление проектом или производственную поддержку.

## Стандарт описания модуля

Каждый модуль должен отвечать на одни и те же вопросы:

1. Какую проблему он решает?
2. Когда он начинается и когда заканчивается?
3. Кто пользуется результатом?
4. Какие входные данные нужны?
5. Какие сущности и признаки создаются?
6. Какие выходные артефакты получаются?
7. Как проверить, что модуль выполнен?
8. Что нельзя хранить в GitHub?

Проектные файлы, клиентские чертежи, коммерческие цены и конфиденциальные
исходники должны храниться вне этого репозитория. GitHub хранит метод, а не
проектные данные.
