# Implementation notes: BPM-002 DWG viewer

## Approved behavior

Утвержденная версия интерфейса основана на v5 `mobile_pan`.

Ключевые решения:

- HTML полностью автономный: SVG-превью встраиваются как base64 data URI.
- Большое превью справа вставляется как inline SVG, а не как обычный `img`, чтобы надежнее работал масштаб и панорамирование.
- Масштаб применяется только к SVG в правой области, не к странице браузера.
- Панорамирование работает через `scrollLeft` и `scrollTop` контейнера предпросмотра.
- Для телефона добавлены touch-обработчики с `preventDefault`, чтобы страница не перехватывала жест внутри окна чертежа.
- Полотно вокруг SVG получает дополнительные поля, чтобы можно было дойти до любого края чертежа при увеличении.

## Dependencies

- ODA File Converter для конвертации DWG в DXF.
- Python 3.
- `ezdxf` для чтения DXF и рендера SVG.

Минимальная установка Python-зависимости:

```powershell
python -m pip install ezdxf
```

## ODA command

Проверенная команда ODA для папки:

```powershell
& "C:\Program Files\ODA\ODAFileConverter 27.1.0\ODAFileConverter.exe" `
  "C:\path\to\dwg-input" `
  "C:\path\to\dxf-output" `
  "ACAD2018" `
  "DXF" `
  "1" `
  "1" `
  "*.DWG"
```

Пятый параметр `1` включает рекурсивную обработку.

## Rendering rule

Для DWG, где содержимое находится не в Model, рендер должен выбирать первый paper layout, если он есть. Если paper layout отсутствует, используется modelspace.

## HTML style

Интерфейс должен использовать палитру P02 Apple Gray Direct:

- layer 1: `#fbfbfa`;
- layer 2: `#f3f4f4`;
- layer 3: `#e9ebeb`;
- border: `#d5d8d8`;
- text: `#1f2328`;
- secondary text: `#59636e`.

## Known limitations

- Некоторые DWG могут рендериться долго или не рендериться из-за особенностей DXF/SVG.
- Текст и сложные штриховки могут отличаться от AutoCAD.
- Модуль не заменяет CAD-проверку, а дает быстрый визуальный просмотр.
