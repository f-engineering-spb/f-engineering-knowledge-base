# Approval: BPM-002 DWG viewer

Статус: `Approved`

Дата фиксации: 2026-07-07

## Что утверждено

Утвержден модуль создания автономного HTML-просмотрщика DWG-файлов без AutoCAD и без PDF-подложек.

Утвержденный интерфейс соответствует версии v5 `mobile_pan`:

- компьютер: левая колонка с миниатюрами, правая область с большим чертежом, масштаб и pan;
- телефон вертикально: список сверху, просмотр снизу, touch-pan по чертежу;
- телефон горизонтально: компактные верхние панели, полный pan по чертежу;
- standalone HTML можно переслать пользователю без исходных DWG.

## Решение по GitHub

В GitHub фиксируется метод, код сборщика и правила. Тестовый HTML, исходные DWG, DXF и SVG-превью не коммитятся, потому что могут содержать клиентские данные и являются тяжелыми производными артефактами.

## Дальнейшее развитие

BPM-002 используется как самостоятельный кирпичик. В будущих работах его можно комбинировать с PDF-viewer, поиском, фильтрами, Google Sheets registry и более сложными системами навигации по входящей документации.
