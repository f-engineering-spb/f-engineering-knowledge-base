# Инструкция оператору: BPM-002 DWG viewer

## Когда запускать

Запускайте модуль, когда на входе есть папка с DWG-файлами и нужно быстро получить визуальный HTML-реестр без AutoCAD и без PDF-подложек.

Типовые случаи:

- заказчик прислал только DWG;
- PDF отсутствуют или неполные;
- нужно быстро понять состав чертежей на телефоне;
- нужно отправить визуальный навигатор человеку без AutoCAD.

## Предварительные условия

1. На рабочем компьютере установлен ODA File Converter.
2. Python доступен из командной строки.
3. Установлен пакет `ezdxf`.
4. Входная папка содержит DWG-файлы.
5. Рабочая папка сборки не является GitHub-папкой с клиентскими данными.

Проверенная версия ODA:

```powershell
C:\Program Files\ODA\ODAFileConverter 27.1.0\ODAFileConverter.exe
```

## Базовая команда

```powershell
python scripts\build_dwg_viewer.py "C:\path\to\dwg-input" "C:\path\to\viewer-output" --title "DWG viewer"
```

На выходе в папке `viewer-output` появляются:

- `index.html` - автономный HTML-viewer;
- `registry.json` - реестр файлов и встроенных превью;
- `dxf/` - временные DXF после ODA;
- `previews/` - временные SVG-превью.

Для передачи пользователю обычно нужен только `index.html`.

## Как работать с HTML

1. Откройте `index.html` в браузере.
2. Слева выберите DWG по миниатюре, имени и пути.
3. Справа смотрите большой чертеж.
4. Используйте `+`, `-`, `Вписать` для масштаба.
5. Таскайте большой чертеж мышью или пальцем внутри правой области.
6. На телефоне проверяйте вертикальную и горизонтальную ориентацию.

## Проверка перед передачей

Откройте HTML локально и проверьте:

- слева видны миниатюры;
- путь к файлу читается от корня входной папки;
- справа отображается большой чертеж;
- масштаб меняется без масштабирования всей страницы браузера;
- панорамирование работает по горизонтали и вертикали;
- на телефоне страница не перехватывает движение внутри чертежа;
- HTML открывается без доступа к исходным DWG.

## Что нельзя делать

- Не коммитить DWG, DXF, SVG-превью, готовые HTML с клиентскими данными в GitHub.
- Не использовать PDF как обязательный источник картинки для этого модуля.
- Не требовать AutoCAD у получателя HTML.
- Не считать HTML юридическим комплектом документации: это навигатор и средство быстрого просмотра.

## Если рендер идет медленно

Некоторые DWG дают тяжелые DXF/SVG. Для больших папок допускается:

- сначала собрать тестовую подвыборку;
- сортировать DWG по размеру и проверять малые файлы первыми;
- добавить таймауты рендера в будущей версии;
- фиксировать файлы, на которых рендер не удался, в `registry.json` со статусом ошибки.
