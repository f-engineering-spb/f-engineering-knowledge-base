# Quality checklist: BPM-002 DWG viewer

## Input checks

- [ ] Входная папка существует.
- [ ] Входная папка содержит DWG.
- [ ] Обработка берет только DWG, PDF не используются как источник картинок.
- [ ] Относительные пути считаются от корня входной папки.

## Build checks

- [ ] ODA File Converter найден.
- [ ] DXF создаются в рабочей папке сборки.
- [ ] SVG-превью создаются для большинства DWG.
- [ ] Ошибки отдельных файлов не останавливают всю сборку.
- [ ] `registry.json` содержит статус каждого DWG.
- [ ] `index.html` создается как standalone HTML.

## Desktop viewer checks

- [ ] Левая колонка прокручивается отдельно.
- [ ] Миниатюры видны.
- [ ] Под миниатюрой видны имя и путь.
- [ ] При выборе миниатюры справа меняется большой чертеж.
- [ ] Масштаб меняется кнопками `+`, `-`, `Вписать`.
- [ ] Масштабируется только чертеж, не вся страница.
- [ ] Чертеж можно таскать мышью вверх, вниз, влево и вправо.
- [ ] При увеличении можно дойти до всех краев листа.

## Mobile viewer checks

- [ ] В вертикальной ориентации список и просмотр помещаются в экран.
- [ ] В горизонтальной ориентации верхняя панель просмотра не раздувается.
- [ ] Большой чертеж можно таскать пальцем вверх, вниз, влево и вправо.
- [ ] Страница телефона не перехватывает жест внутри окна чертежа.
- [ ] Кнопки масштаба доступны и не перекрывают название.
- [ ] `Вписать` возвращает чертеж в читаемый базовый масштаб.

## GitHub checks

- [ ] В GitHub не добавлены DWG.
- [ ] В GitHub не добавлены DXF.
- [ ] В GitHub не добавлены SVG-превью клиентских файлов.
- [ ] В GitHub не добавлен standalone HTML с клиентскими данными.
- [ ] В GitHub добавлены только правила, инструкции и reusable scripts.

## Approval criteria

Модуль можно считать `Approved`, если:

- он успешно собрал хотя бы один тестовый комплект DWG;
- HTML открыт на компьютере;
- HTML открыт на телефоне в вертикальной и горизонтальной ориентации;
- пользователь подтвердил, что результат годится по смыслу и управлению;
- в GitHub не попали клиентские данные.
