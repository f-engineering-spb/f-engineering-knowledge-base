# Модули бизнес-процессов

Эта папка содержит повторяемые модули, которые можно подключать к большим
процессам компании. Модуль должен быть достаточно маленьким, чтобы применяться
самостоятельно, и достаточно понятным, чтобы его можно было передать другому
сотруднику.

Модули не являются архивом проекта. Они описывают, как выполнять повторяемую
работу.

| ID | Модуль | Типовая стадия | Основной результат |
|---|---|---|---|
| BPM-001 | [Первичная индексация входящей документации](incoming-documentation-indexer/README.md) | Старт тендера, старт проектирования, последующее обращение к архиву исходников | Реестр файлов, таблица сущностей, HTML / Apps Script просмотрщик |
