# Официальный веб-сайт и брендбук инженерного бюро «ФЕРО» (ferospb.info / ferospb.ru)

В данной директории зафиксирован полный эталонный код главной страницы, интерактивного брендбука и всех графических ассетов фирменного стиля.

## 1. Структура файлов и разделов

- `index.html` — Главная страница официального сайта «ФЕРО» (презентационная медная версия).
- `brandbook.html` (а также `brandbook/index.html`) — Интерактивный онлайн-брендбук:
  - Раздел 01: Архитектура двухуровневой системы стиля (Презентационная медь #D6632B vs Рабочий Ч/Б контур #111111).
  - Раздел 02: Корпоративная цветовая палитра (CMYK, RGB, HEX).
  - Раздел 03: Фирменный логотип и монограмма «Ф» (вектор и растр).
  - Раздел 04: Чертежные штампы СПДС ГОСТ Р 21.101-2020 (Форма 1: 185×55 мм, Форма 3: 185×15 мм, блок логотипа 42×10 мм).
  - Раздел 05: Официальные фирменные бланки А4 (DOCX и PDF).
  - Раздел 06: Электронные почтовые подписи (Email Signatures).
  - Раздел 07: Центр загрузок (Download Center) со всеми архивами и прямыми ссылками.
- `index_contour.html` — Альтернативная контурная версия главной страницы.
- `index_contour_copper.html` — Медная контурная версия главной страницы.
- `assets/` — Каталог всех медиафайлов, чертежей DXF, векторных SVG, растровых PNG/ICO, документов PDF/DOCX и скачиваемых ZIP-пакетов:
  - `fero_site_full.zip` — Полный автономный дистрибутив сайта для развертывания на любом веб-сервере.
  - `fero_brandbook_complete.zip` — Мастер-пакет всех исходников бренда (11.8 MB).
  - `fero_brandbook_presentation_copper.zip` — Презентационный пакет (5.7 MB).
  - `fero_brandbook_working_bw.zip` — Рабочий монохромный пакет (813 KB).
  - `fero_mini_catalog.pdf` — Официальный мини-каталог бюро (39 страниц).

## 2. Развертывание сайта

Сайт полностью статичен и не требует баз данных или серверного рантайма (Node.js/PHP/Python):
1. Скопировать все содержимое папки `site/` (или распаковать `fero_site_full.zip`) в корневую директорию любого веб-сервера (Nginx, Apache, Caddy, GitHub Pages, Netlify или хостинг Reg.ru/Beget).
2. Настроить отдачу статических файлов и MIME-типов для `.svg`, `.dxf`, `.pdf`, `.docx`, `.zip`.
