# Официальный сайт инженерного бюро «ФЕРО» (ferospb.info)

В данной директории зафиксирован эталонный код главной страницы и векторные ассеты нового визуального стиля.

## Структура
- `index.html` — Исходный код главной страницы сайта с разметкой первого экрана, навигацией и стилями.
- `assets/`
  - `fero_3d_sun_desc_unit.svg` — Основной векторный логотип (3D «ФЕРО» + солнце 45° + дескриптор «ФАСАДНЫЙ ИНЖИНИРИНГ»).
  - `fero_3d_sun_desc_unit.png` — Ultra-HD растровый прозрачный логотип.
  - `fero_3d_sun_unit.svg` — Компактный векторный логотип без дескриптора.
  - `fero_3d_sun_unit.png` — Компактный растровый логотип.

Регламент использования и отступов описан в [docs/FERO_LOGO_STANDARDS_AND_GUIDELINES.md](../docs/FERO_LOGO_STANDARDS_AND_GUIDELINES.md).
