------------------------------------------------------------------------
СПОСОБ 1: САМЫЙ БЫСТРЫЙ И УНИВЕРСАЛЬНЫЙ (ЧЕРЕЗ БРАУЗЕР - 30 СЕКУНД)
Подходит для: Яндекс.Почта, Mail.ru, Gmail, Outlook Web, Thunderbird, Apple Mail
------------------------------------------------------------------------
1. Откройте нужный файл подписи (например, fero_email_signature_copper.html) 
   в любом браузере (Chrome, Яндекс.Браузер, Edge, Safari).
2. Выделите подпись целиком мышью (или нажмите Ctrl + A, если открыта только страница подписи).
3. Скопируйте выделенное (нажмите Ctrl + C).
4. Откройте настройки вашей почтовой программы:
   - В Яндекс.Почте: Настройки (шестеренка вверху справа) -> Информация об отправителе -> Подпись.
   - В Mail.ru: Настройки -> Имя и подпись.
   - В Gmail: Настройки (шестеренка) -> Все настройки -> Общие -> Подпись.
   - В MS Outlook (веб): Настройки -> Почта -> Создание сообщений -> Подпись.
5. Вставьте скопированную подпись в поле редактора (нажмите Ctrl + V).
6. Замените образец имени («Алексей Иванов») и должности («Директор по развитию...») на ваши реальные данные.
7. Нажмите «Сохранить». Готово!

------------------------------------------------------------------------
СПОСОБ 2: ДЛЯ MICROSOFT OUTLOOK (НАСТОЛЬНОЕ ПРИЛОЖЕНИЕ ДЛЯ WINDOWS)
------------------------------------------------------------------------
1. В Outlook откройте меню «Файл» -> «Параметры» -> «Почта» -> «Подписи...».
2. Нажмите кнопку «Создать», введите имя (например, «ФЕРО Медь»).
3. Откройте файл fero_email_signature_copper.html в браузере, выделите, нажмите Ctrl + C.
4. Вставьте (Ctrl + V) в нижнее поле окна подписи в Outlook.
5. Измените ФИО, должность и телефон на свои.
6. Выберите созданную подпись в полях «Новые сообщения» и «Ответы/пересылка».
7. Нажмите «ОК».
