# Стандарт марочного аудита чертежей

Статус: `Candidate`

## Назначение

Этот стандарт применяется, когда из комплекта PDF/DWG/DXF/XLSX нужно получить полный проверяемый реестр марок, типов изделий, материалов и объемов для коммерческого предложения, спецификации или аудита чертежей.

Цель — не только получить итоговую сумму, но и построить рабочий словарь проекта: что означает каждая маркировка, на каком листе она найдена, какой объем ей соответствует, где есть комментарии проектировщика и какие позиции требуют дочитки.

## Когда применять

Применять при задачах вида:

- `собери все марки фасада`;
- `расшифруй обозначения на чертежах`;
- `сделай спецификацию по всем маркам`;
- `подготовь объемы для коммерческого предложения`;
- `проверь, что в фасадной спецификации ничего не потеряно`;
- `собери Google таблицу с марками, объемами и источниками`.

Для фасадов применять совместно с:

- `methodologies/Engineering_Drawing_Audit/`;
- `methodologies/Complete_Facade_Commercial_Specification/`;
- `proposals/Facade_Full_Scope_Multi_Contour_Audit.md`.

## Обязательный результат

Основной результат — таблица, предпочтительно Google Sheets, а перед импортом локальный `.xlsx` для проверки.

В книге должны быть:

1. `Словарь обозначений` — все найденные префиксы и марки с расшифровкой.
2. Отдельные листы по крупным семействам марок: например `ОК`, `ВР`, `ЖР`, `Дп`, `МпР`, `Кп`, `ОГ`, `СкБ`, `СкТ`, `ОГС`, `СФ`, `НкТ`, `У`.
3. Листы материалов по авторским ведомостям: кирпич, штукатурка, камень, металл, утеплитель, мембраны, подсистема, если они есть.
4. Лист `Прочие объемы` для козырьков, ограждений, покрытий, люков, дверей, светильников и элементов, которые нельзя смешивать с площадью основной оболочки.
5. Лист `Источники` или колонка источника в каждом листе.
6. Лист `Расхождения / вопросы`, если по марке найдено обозначение, но объем не извлечен надежно.

## Обязательные колонки

Для каждой марки или позиции фиксировать:

| Колонка | Назначение |
|---|---|
| Марка / обозначение | Точная маркировка с чертежа, без нормализации, которая теряет смысл |
| Расшифровка | Что означает марка в проекте |
| Физический смысл | Что это: окно, витраж, панель, решетка, облицовка, утеплитель, элемент цоколя и т.д. |
| Источник | Раздел, лист, таблица, примечание или вид, откуда взято |
| Ссылка на лист | Путь/URL/имя PDF/DWG-листа или Google Drive-ссылка |
| Корпус / зона / фасад | Если доступно из ведомости или выносок |
| Размеры | Ширина, высота, длина, толщина и другие параметры, если есть |
| Количество | Числовое значение, пригодное для суммирования |
| Единица | м2, м.п., шт., компл., м3 и т.д. |
| Площадь / объем | Числовое значение, пригодное для суммирования |
| Метод | Указано автором, рассчитано, оценка, не определено |
| Достоверность | A/B/C/D по стандарту Engineering_Drawing_Audit |
| Комментарий | Примечания проектировщика, требования, оговорки, что проверить |

## Требования к числам

Все количества, площади, длины, объемы и стоимости должны быть записаны как числовые значения таблицы, а не как текст.

Запрещено:

- писать `120,87 м2` в одной ячейке количества;
- смешивать единицу измерения и число;
- использовать текстовые числа, которые не суммируются;
- объединять разные единицы измерения в один итог без пояснения.

Правильно:

- `Площадь, м2` = `120.87`;
- `Ед.` = `м2`;
- `Количество` = `10`;
- `Комментарий` = текстовое пояснение отдельно.

## Черно-белый формат

По умолчанию реестр марок делать в черно-белом рабочем стиле:

- белый фон;
- черный текст;
- жирные заголовки;
- тонкие черные или серые границы;
- без цветовых статусов, заливок и декоративных палитр.

Статус надежности писать текстом в отдельной колонке, например `A — указано автором`, `B — рассчитано`, `C — оценка`, `D — не определено`.

## Рабочий процесс

1. Зарегистрировать комплект исходников и листов.
2. Извлечь текст из PDF и, если возможно, данные из DWG/DXF/XLSX.
3. Просканировать все листы на марки и префиксы: буквенно-цифровые обозначения, выноски, легенды, ведомости, таблицы, примечания.
4. Составить первичный словарь всех найденных обозначений.
5. Найти листы, где каждая марка расшифровывается.
6. Для каждого семейства марок создать отдельный лист таблицы.
7. Внести все строки ведомостей по маркам, не сворачивая разные типы в один итог, пока не сохранены исходные строки.
8. Рассчитать площади/длины только воспроизводимыми формулами или принять авторские значения с пометкой.
9. Ссылаться на лист-источник в каждой строке.
10. Переносить примечания проектировщика в колонку `Комментарий`, если они есть.
11. Если марка найдена на фасаде, но ее объем не найден, оставить строку со статусом `D — не определено` или `C — требует дочитки`, а не удалять ее.
12. Сформировать сводку по семействам марок и отдельные итоги по единицам измерения.
13. Проверить, что числовые колонки суммируются в Excel/Google Sheets.
14. Импортировать проверенный `.xlsx` в Google Sheets, если пользователю удобнее работать там.

## Правило полноты

Нельзя ограничиваться только листами, где явно написано `ведомость`.

Нужно шерстить:

- общие фасады;
- планы и разрезы, если там есть марки;
- узлы и детали;
- листы раскладок;
- ведомости изделий;
- ведомости материалов;
- общие данные и примечания;
- листы с требованиями к материалам и монтажу.

Если обозначение встречается на фасаде, но не найдено в ведомости, оно все равно должно попасть в словарь и в лист вопросов.

## Контроль качества

Перед выдачей результата проверить:

1. Все числовые колонки действительно суммируются.
2. В каждой строке есть источник.
3. Для каждой марки есть расшифровка или статус `не расшифровано`.
4. Не потеряны комментарии проектировщика.
5. Итоги по маркам сходятся с авторскими итогами, если они есть.
6. Разные единицы измерения не сложены в один физический итог.
7. Локальный `.xlsx` и Google Sheets содержат одинаковые листы и значения.
8. Кириллица в путях, листах и комментариях не повреждена.

## Для коммерческого предложения

Такой реестр является базой для КП:

- заказчик видит проверяемые объемы;
- команда понимает, где лежит источник каждой цифры;
- можно быстро менять ставку/цену по семействам работ;
- можно отделять проектирование светопрозрачных конструкций, облицовки, подсистемы, малых изделий и дополнительных элементов;
- можно фиксировать риски по маркам, которые не удалось надежно посчитать.
