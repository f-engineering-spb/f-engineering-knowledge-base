# Контрольный чек-лист аудита

## Быстрая визуальная проверка

Отчет считается готовым к передаче на проверку, если пользователь может ответить `да` на следующие вопросы:

| Проверка | Что должно быть видно |
|---|---|
| Исходники | Полный список файлов, листов, дат и ревизий |
| Масштаб и единицы | Единицы CAD, масштаб листов, контрольные размеры |
| Габариты | Ширина, высота, длина или периметр каждого основного вида |
| Формула | Минимум одна полностью раскрытая контрольная позиция |
| Итоги по блокам | Отдельные суммы по фасадам, этажам, материалам или типам |
| Общий итог | Контрольная сумма, складывающаяся из видимых подытогов |
| Баланс | Общая площадь равна сумме классифицированных и необъясненных зон |
| Второй метод | Ключевой итог проверен независимым способом |
| Расхождения | Показаны абсолютная разница, процент и объяснение |
| Дубли | Перечислены исключенные повторные виды и детали |
| Неопределенное | Отдельно показано, что нельзя надежно посчитать |
| Достоверность | Каждая итоговая цифра имеет статус A, B, C или D |
| Полнота фасадов | Проверены несветопрозрачные, светопрозрачные и все дополнительные фасадные контуры |
| Наложенные контуры | Ограждения, ламели, экраны и аналогичные элементы учтены отдельно и не вычтены из основного фасада |
| Проверочные превью | После расчётных разделов доступны раскрываемые превью полных исходных листов |

## Правило светофора

- `Зеленый`: расхождение не более 2%, источник и метод подтверждены.
- `Желтый`: оценка или расхождение 2–5%, требуется уточнение.
- `Красный`: расхождение более 5%, конфликт исходников или отсутствуют критические данные.
