# Эталон клиентской дорожной карты

Шаблон применяется для клиентских дорожных карт запуска, создания, внедрения, восстановления и масштабирования проектов, объектов, функций, направлений и производств.

## Основные файлы

- Правила структуры и оформления: `document-standards/Client_Roadmap_Style.md`.
- Методика смысловой декомпозиции: `methodologies/Roadmap_Information_Architecture.md`.
- HTML-шаблон: `Client_Roadmap_Reference.html`.
- Содержательный пример выбирается из применимого проекта и не хранится в базе
  знаний без обезличивания и отдельного утверждения.

## Порядок применения

1. Использовать HTML-шаблон как основу.
2. До верстки разложить исходные данные по смысловым контурам и связать их в единый процесс.
3. Заменить название, метаданные, KPI и разделы под предмет задачи.
4. Сохранить логическую цепочку: цель → контуры → ресурсы → результат → дефициты → люди → этапы → риски → финансы.
5. Сохранить палитру, типографику, интервалы и компоненты.
6. Не переносить внутреннюю историю анализа в клиентский документ.
7. Финансовые расчеты размещать отдельным блоком и выпускать расчетную XLSX-модель.
8. Проверить смысловую связность, настольную, мобильную и печатную версии.
