# Эталон аналитического отчета

Файл `Analytical_Report_Reference.md` является утвержденным пользователем структурным эталоном для аналитических записок, исследований, классификаторов, нормативных обзоров и технических отчетов.

При создании нового документа сохранять:

- композицию титульного блока;
- логику содержания;
- структуру резюме, аналитических разделов, таблиц и проверочных блоков;
- правила адаптации в HTML, если итоговый документ верстается как HTML;
- печатный режим, если он нужен для передачи результата.

Правила применения находятся в:

`document-standards/HTML_Analytical_Report_Style.md`
