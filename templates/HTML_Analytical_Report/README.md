# Эталон HTML-аналитического отчета

Файл `Analytical_Report_Reference.html` является утвержденным пользователем визуальным эталоном для аналитических записок, исследований, классификаторов, нормативных обзоров и технических отчетов.

При создании нового документа сохранять:

- композицию титульного блока;
- шрифты и цветовую гамму;
- боковое содержание;
- оформление основной области и таблиц;
- мобильный карточный режим таблиц;
- кнопку возврата наверх;
- печатный режим.

Правила применения находятся в:

`document-standards/HTML_Analytical_Report_Style.md`
