# Шаблон постановки задачи на документ

Можно копировать этот шаблон в чат при новой задаче.

## Проект

Например: Moskino / Armenia / Georgia / Barrikady_SPb / новый проект.

## Что нужно получить

Например: протокол, аналитическая записка, таблица задач, презентация, PDF, письмо.

## Входные материалы

Где лежат файлы или что нужно использовать из текста сообщения.

## Для кого документ

Руководитель, заказчик, рабочая группа, внутреннее использование.

## Что особенно важно

Например: выделить проблематику, назначить ответственных, собрать риски, привести к красивому виду, сделать версию для отправки.

## Формат результата

Например: `.docx`, `.xlsx`, `.pptx`, `.pdf`.

## Дополнительные правила

Сроки, стиль, ограничения, обязательные разделы.
