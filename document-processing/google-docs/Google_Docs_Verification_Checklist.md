# Google Docs Verification Checklist

Статус: `Candidate`

Назначение: контрольный список после правок Google Docs документов / post-edit verification checklist.

Применять после смысловых правок, правки таблиц, форматирования и любых операций записи в Google Docs.

## Обязательная проверка после смысловой правки

1. Измененный пункт найден в документе.
2. Новая редакция соответствует согласованному черновику.
3. Соседние пункты не изменены без запроса пользователя.
4. Автоматическая нумерация / automatic numbering не распалась.
5. Термины использованы в согласованной редакции.
6. Нет случайных дублей текста.
7. Нет mojibake, битой кириллицы или странных символов.

## Проверка после правки таблиц

1. Изменены только нужные строки и ячейки.
2. Итоговая сумма / total пересчитана правильно.
3. Проценты / percentages соответствуют суммам.
4. НДС / VAT, если указан, не противоречит итоговой сумме.
5. Таблица не потеряла строки и столбцы.
6. Названия этапов не изменились, если пользователь просил менять только суммы.
7. Соседние приложения не затронуты.

## Проверка после форматирования

1. Лишние пустые строки удалены только там, где это было согласовано.
2. Расстояния между разделами выглядят единообразно.
3. Заголовки разделов не потеряли текст.
4. Подписи сторон и реквизиты остались на месте.
5. Таблицы не сместились и не потеряли структуру.
6. Нумерация пунктов и подпунктов сохранилась.
7. Содержание документа не изменилось под видом форматирования.

## Проверка перед ответом пользователю

В финальном ответе указать:

1. Что изменено.
2. Где изменено: раздел, пункт, приложение, строка таблицы.
3. Какие контрольные значения проверены.
4. Что не изменялось.
5. Ссылку на Google Docs документ.

## Если обнаружена проблема

Если после записи обнаружена проблема:

1. Не продолжать следующие правки.
2. Сообщить пользователю, что именно найдено.
3. Предложить безопасный план исправления.
4. Не маскировать ошибку и не утверждать, что правка выполнена идеально.
