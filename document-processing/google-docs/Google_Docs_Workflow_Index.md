# Google Docs Workflow Index

Статус: `Candidate`

Назначение: индекс правил для работы с нативными Google Docs документами / native Google Docs documents.

Эти правила применяются, когда пользователь просит подготовить, проверить, отредактировать или отформатировать договоры, приложения, технические задания, протоколы, акты и другие юридически или технически значимые документы в Google Docs.

## Принцип подключения правил

Агент не должен читать всю базу знаний. Для задач Google Docs нужно подключать только этот индекс и те правила, которые относятся к конкретной операции:

1. `Google_Docs_Contract_Text_Editing.md`
   - смысловая правка текста договора / contract wording amendment;
   - черновик на экран / draft preview;
   - согласование формулировки / wording approval;
   - точечная вставка или замена / targeted insertion or replacement;
   - контрольное чтение / verification read.

2. `Google_Docs_Contract_Formatting.md`
   - удаление лишних пустых строк / removing redundant blank lines;
   - выравнивание расстояний между разделами / normalizing spacing between sections;
   - приведение заголовков к единому виду / normalizing section headings;
   - проверка автоматической нумерации / automatic numbering check;
   - аккуратная работа с таблицами / safe table formatting.

3. `Google_Docs_Verification_Checklist.md`
   - проверка после правок / post-edit verification;
   - сверка измененных фрагментов / changed-fragment verification;
   - контроль отсутствия mojibake и повреждения структуры / structure and encoding check.

## Общие ограничения

1. Работать в нативном Google Docs / native Google Docs, если документ уже находится в Google Docs.
2. Не пересобирать документ целиком через экспорт, импорт, Markdown replacement или полную перезапись документа.
3. Не менять документ до согласования, если задача касается смысла договора.
4. Не использовать глобальные замены / global replacements, если фрагмент может встречаться в нескольких местах.
5. После любой записи делать контрольное чтение измененного участка.
6. Не переносить в репозиторий клиентские тексты, реквизиты, суммы и конфиденциальные данные.

## Когда дополнять индекс

Если при работе с Google Docs отработан новый повторяемый прием / repeatable technique, добавить его либо в существующее правило, либо создать отдельный файл в этой папке со статусом `Candidate`.
