# Google Docs Contract Formatting

Статус: `Candidate`

Назначение: стартовая методика форматирования договоров в Google Docs / contract formatting methodology.

Это правило пока является заготовкой для следующего этапа работы. Оно должно дополняться после практических пилотов форматирования.

## Цель

Приводить договор к аккуратному и читаемому виду без изменения смысла и текста документа.

Форматирование / formatting не должно менять содержание / content.

## Типовые операции

1. Удаление лишних пустых строк / removing redundant blank lines.
2. Выравнивание расстояний между разделами / normalizing spacing between sections.
3. Приведение заголовков разделов к единому виду / normalizing section headings.
4. Проверка автоматической нумерации / automatic numbering check.
5. Выравнивание таблиц приложений / appendix table alignment.
6. Удаление случайных двойных пробелов / removing accidental double spaces.
7. Приведение блоков подписей к единому виду / normalizing signature blocks.

## Рабочий протокол

1. Сначала выполнить смысловые правки / content edits, если они есть.
2. Перед форматированием прочитать документ и определить проблемные места.
3. Показать пользователю план форматирования на экран.
4. Не менять текстовые формулировки без отдельного согласования.
5. Форматировать точечно: раздел, таблицу, блок подписей или конкретный диапазон.
6. После форматирования перечитать измененные участки.
7. Проверить, что текст, суммы, пункты и нумерация не изменились.

## Запрещенные приемы

1. Не пересобирать документ целиком.
2. Не использовать массовое форматирование всего документа без плана.
3. Не менять стиль таблиц, если пользователь просит только убрать пустые строки.
4. Не исправлять юридические формулировки под видом форматирования.
5. Не ломать автоматическую нумерацию / automatic numbering.

## Проверки после форматирования

1. Нет лишних пустых строк.
2. Заголовки визуально единообразны.
3. Таблицы не потеряли строки и столбцы.
4. Нумерация пунктов сохранилась.
5. Подписи сторон остались на месте.
6. Суммы и реквизиты не изменились.
7. Кириллица отображается корректно, без mojibake.

## Следующий пилот

Следующий практический этап: отработать безопасное удаление лишних пустых строк и нормализацию расстояний между разделами в Google Docs договоре.

После успешного пилота дополнить это правило конкретными проверенными приемами / verified techniques.
