# F-Engineering Knowledge Base

Central repository for approved F-Engineering instructions, business-process
modules, service workflows, visual standards, and governance rules.

Start with [START_HERE.md](START_HERE.md).

Reusable business-process modules are stored in
[business-processes/](business-processes/).

This repository is not an application runtime. Product code, including
F-Engineering Launcher, must live in separate product repositories. See
[docs/Repository_Boundaries.md](docs/Repository_Boundaries.md).

For the GitHub workflow, knowledge contribution process, conflict checks, and
the practical map of what the repository contains, read
[docs/GitHub_Knowledge_Base_Workflow.md](docs/GitHub_Knowledge_Base_Workflow.md).
