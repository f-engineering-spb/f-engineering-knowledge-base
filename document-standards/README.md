# Document standards

Approved content, structure, formatting, and quality requirements for documents.

Key visual standards:

- `Document_Style_Guide.md` - общий стиль документов.
- `HTML_Mobile_Standard.md` - обязательная мобильная проверка HTML.
- `Client_Roadmap_Style.md` - клиентские дорожные карты и планы.
- `PNG_Infographic_Roadmap_Style.md` - один наглядный PNG-лист дорожной карты
  или маршрута на основе проверенного HTML/таблицы.
