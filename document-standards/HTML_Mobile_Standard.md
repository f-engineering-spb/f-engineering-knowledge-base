# Стандарт мобильной верстки HTML-документов

## Обязательное требование

Каждый создаваемый или изменяемый HTML-документ должен полностью помещаться по ширине экрана телефона в портретной ориентации.

Пользователь не должен поворачивать телефон или прокручивать страницу горизонтально, чтобы увидеть правую часть документа.

## Базовые правила CSS

1. Всегда использовать:

```css
html, body {
  max-width: 100%;
  overflow-x: hidden;
}

*, *::before, *::after {
  box-sizing: border-box;
  min-width: 0;
}

img, svg, canvas {
  max-width: 100%;
  height: auto;
}
```

2. Для сеток на мобильном экране использовать одну колонку.
3. Длинным словам, ссылкам и значениям разрешать перенос:

```css
overflow-wrap: anywhere;
word-break: break-word;
```

4. На мобильном экране отменять `white-space: nowrap` у таблиц и числовых ячеек.
5. Широкие таблицы должны физически помещаться в экран:

```css
table { width: 100%; table-layout: fixed; }
th, td {
  white-space: normal !important;
  overflow-wrap: anywhere;
  word-break: break-word;
}
```

6. На экране до 600 px уменьшать внутренние отступы, размер заголовков и размер текста таблиц.
7. Декоративные элементы с абсолютным позиционированием не должны выходить за экран.

## Исключение для расчетных спецификаций

Если пользователь ожидает вид электронной таблицы и одна строка соответствует одному типоразмеру/марке:

- не преобразовывать строки спецификации в карточки;
- сохранять единую таблицу;
- помещать таблицу в отдельный контейнер с локальной горизонтальной и вертикальной прокруткой;
- не допускать горизонтальной прокрутки всей HTML-страницы;
- использовать закрепленную шапку и, при необходимости, закрепленную итоговую строку;
- центрировать заголовки и данные в ячейках, если пользователь не указал иное.

## Обязательная проверка

Перед передачей HTML:

1. Открыть документ в браузере.
2. Проверить viewport шириной `390 px` и высотой около `844 px`.
3. Проверить условие:

```text
document.documentElement.scrollWidth <= document.documentElement.clientWidth
```

4. Дополнительно проверить самые широкие таблицы и длинные заголовки.
5. Если `scrollWidth` больше `clientWidth`, исправить верстку до передачи файла.

Проверку выполнять для каждого итогового HTML-файла, а не только для шаблона.
