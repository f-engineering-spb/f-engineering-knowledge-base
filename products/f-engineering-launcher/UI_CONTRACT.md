# F-Engineering Launcher — контракт интерфейса

Статус: `Candidate`  
Родительский материал: `PRD-001`

## 1. Постоянная компоновка

Интерфейс состоит из:

1. верхней панели с названием продукта и двумя контекстными кнопками;
2. тонкой строки состояния папки;
3. изменяемой левой панели дерева;
4. основной диалоговой области;
5. закрепленной полосы выполнения во время работы;
6. отдельного многострочного поля ввода.

Название проекта не должно одновременно дублироваться в верхней панели и в
корне дерева.

## 2. Две верхние кнопки

| Состояние | Левая кнопка | Правая кнопка |
|---|---|---|
| Проект не выбран | `Выбрать папку` — открыть системный выбор папки | `Показать результат` — неактивна |
| Проект загружен | `Открыть папку объекта` — открыть корень в Проводнике | `Показать результат` — неактивна |
| Модуль выполняется | `Открыть папку объекта` | `Показать результат` — неактивна |
| Результат создан | `Показать в папке` — выделить результат в Проводнике | `Показать результат` — вернуть карточку результата в поле зрения |

`Показать результат` не запускает основной файл и не открывает Проводник.
Она восстанавливает и подсвечивает карточку последнего результата в диалоге.

Карточка результата содержит отдельные действия:

- открыть основной результат;
- открыть папку результата.

## 3. Строка состояния папки

Большие статистические карточки не используются.

Пример компактной строки:

```text
● Папка считана · Папок 24 · Файлов 196 · PDF 101 · DWG 94 · Прочие 1
```

Название проекта в строке не повторяется.

Семантика маркера:

- зеленый — считывание завершено;
- желтый — считывание продолжается или есть предупреждение;
- красный — ошибка;
- синий — активная обработка модулем.

## 4. Дерево проекта

- дерево отражает реальную структуру на диске;
- вертикальный разделитель перемещается мышью;
- дерево можно расширить, сузить и полностью свернуть;
- после сворачивания остается ручка восстановления;
- двойное нажатие возвращает стандартную ширину;
- выбранная ширина запоминается;
- новый результат временно подсвечивается.

## 5. Поле ввода

- отделено от истории диалога;
- 4–5 строк по умолчанию;
- допускает увеличение примерно до 10 строк;
- после достижения максимума получает внутреннюю прокрутку;
- содержит голосовой ввод и кнопку `Ввод`;
- голос сначала преобразуется в редактируемый текст и не отправляется
  автоматически.

## 6. Список подразделений по умолчанию

Справочник является настраиваемым.

1. Коммерция
2. Проектирование
3. Снабжение
4. Логистика
5. Производство
6. Юротдел
7. Финансово-экономическая служба
8. Руководители проектов
9. СМР
10. Офис-менеджер
11. Охрана труда
12. Кадры
13. Иное

Лаунчер не выводит предположение о подходящем подразделении. Он сразу
показывает нумерованный список.

## 7. Состояния диалога

```text
Старт
  -> папка выбрана
  -> дерево считано
  -> выбор подразделения
  -> выбор модуля
  -> сбор обязательных параметров
  -> запуск
  -> выполнение
  -> результат или ошибка
```

## 8. Выполнение

Пользователь видит:

- название модуля;
- номер и название этапа;
- общий процент;
- обработанное и общее количество элементов;
- текущий файл;
- живой журнал;
- действие `Остановить`.

Полоса выполнения закрепляется над полем ввода и не исчезает при прокрутке.

## 9. Масштабирование

- окно изменяет размер стандартными средствами операционной системы;
- поддерживается разворачивание на весь экран;
- при увеличении расширяется полезная площадь, а не все элементы интерфейса;
- панели адаптируются к доступному размеру;
- просмотрщик результата открывается в отдельном масштабируемом окне.

## 10. Визуальная политика

До изменения `DS-010` обязательным источником истины остается
`docs/F_ENGINEERING_VISUAL_STYLE.md`.

Темная IDE-схема, JetBrains Mono как основной интерфейсный шрифт и расширенная
синтаксическая цветовая подсветка должны оформляться отдельным предложением
изменения визуального стандарта.
